# KeepDo (每日行动 · 沉淀长期目标)

> **KeepDo** 是一款以“长期目标”驱动“微小习惯”与“每日行动”的个人全能管理工具。通过天数连击（Streak）、量化进度与行动热力图，让你每天的付出看得见，宏大的目标持续推进。

---

## 🌟 核心特性

- **🎯 长期目标大盘 (Goals Dashboard)**
  - 支持 3 种衡量模型：
    - **天数打卡型**：按坚持天数累计进度（如：复盘 100 天）
    - **数值量化型**：自定义目标与计量单位，提供快速步进器（如：读 12 本书、跑 100 公里）
    - **阶段里程碑型**：可勾选的 Checklist 阶段目标
  - 自动倒计时计算与进度百分比可视化
  - 分类标签过滤（学习、成长、健康、事业、财富等）

- **⚡ 今日专注 (Today Focus)**
  - **习惯打卡**：大圆点一键打卡，自动计算连续天数（🔥 Streak），打卡自动关联推进长期目标数值
  - **每日待办**：高/中/低优先级划分，关联长期目标归属，点击即时划线完成
  - **日历穿梭**：支持切换昨天/今天/明天或任意日期补录与复盘
  - **成就烟花**：今日任务或目标达成时触发五彩纸屑庆祝 🎉

- **📊 统计复盘 (Stats & Heatmap)**
  - **行动热力图**：GitHub 风格近 12 周行动密度网格，见证每一步成长
  - **核心指标**：历史最长连击、累计打卡次数、待办达成总数与目标进度排行

- **🔒 隐私与数据安全**
  - **100% 本地存储**：数据完全保存在当前浏览器 `localStorage` 中，无须服务器，隐私零泄露风险
  - **JSON 备份**：支持一键导出数据为 `.json` 文件，并可随时上传恢复

---

## 🛠️ 技术选型

- **Vue 3**：Composition API (`<script setup>` + TypeScript)
- **Vite 8**：极速构建与开发体验
- **Tailwind CSS v4**：现代轻量原子样式系统，深浅主题自适应
- **Pinia**：响应式状态管理与本地持久化
- **Lucide Icons**：简洁精致的线性矢量图标库
- **Canvas Confetti**：激励仪式感微动效

## 🚀 启动与运行

```bash
# 安装依赖
pnpm install

# 启动本地开发服务
pnpm dev

# 构建生产版本 (含 vue-tsc 类型检查)
pnpm build

# 本地预览生产构建产物
pnpm preview
```
