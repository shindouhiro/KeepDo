# 日历日期详情与具体事项

**目标：** 点击日期可查看当天目标、习惯、待办详情，并进入对应编辑，不只是切换下方页面。

**方案：** 原生日历日期详情 dialog，复用现有 Pinia 数据、目标和习惯编辑弹窗；新增待办编辑 dialog。不修改数据库结构。原生 dialog 提供键盘焦点限制、Escape 关闭及返回触发元素。

## 交互与组件

- 日期格点击后打开详情，另提供「查看当日详情」按钮，日期格补具体事项数量。
- `CalendarDayDialog.vue`：日期导航和选择、各类数量、目标完整说明及里程碑、习惯当日记录、待办优先级和状态；支持打卡、完成与进入编辑。
- `CalendarGoals.vue`：增加详细展示模式，复用目标卡，普通页面保持简洁。
- `TodoModal.vue`：编辑待办名称、日期、优先级、关联目标、完成状态，保存后等待云端确认并显示错误。
- `useNativeDialog.ts`：统一 dialog 打开、关闭、Escape 和焦点恢复行为。
- `TodayView.vue`：编排日期、详情和待办编辑状态；进入已有目标/习惯编辑前关闭详情，避免弹窗重叠。
- 习惯从创建日起属于日程；若旧日期已有打卡记录也保留展示，避免历史日期出现后来新建的习惯。
