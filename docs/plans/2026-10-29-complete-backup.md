# 完整数据备份修复

## 问题与范围

当前 JSON 仅含目标、习惯、待办与分类，遗漏独立存储的目标日记、习惯日记及图片。修复后的完整备份保留现有基础字段，增加格式版本、导出时间、全部日记和内嵌图片，不依赖原账号的图片链接。

## 实现边界

- `shared/backup.ts`：备份格式、校验、图片编码与旧版兼容。
- `server/backup.ts`：读取账号全部日记元数据；按当前数据版本及日记快照校验，在同一事务内恢复基础数据、日记及图片。恢复时重建记录和图片标识，支持跨账号恢复并避免标识冲突，保留主体关联、日期及时间。
- `src/lib/backup.ts`：读取元数据与图片，组成可离线保存的 JSON；任一图片读取失败即报告失败。
- KeepDo store：保留当前页面未保存的基础数据，提供完整导出和恢复入口；旧版导入不删除账号日记。
- `SettingsModal.vue`：展示真实范围、进度和失败原因，操作中防止重复提交；网络失败时可明确选择仅抢救页面基础数据。

## 验证

覆盖超过一页的记录、两类主体、已删除主体的历史日记、图片字节往返、旧版兼容、损坏文件、账号隔离、版本冲突和恢复事务。运行现有单元测试、构建、真实本地 Workers/D1 集成测试及浏览器关键路径。

## 约束

完整导出需要联网获取云端图文记录。现有未提交的日记删除改动保持原样。仓库引用的 `docs/frondend-rule.md` 缺失，采用已提供的 AGENTS 规则及 frond-end 技能。
