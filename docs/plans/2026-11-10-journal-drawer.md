# 日记抽屉调整

用户希望将居中的日记弹窗改为抽屉，便于编辑长记录。

## 组件边界

- `JournalDialog.vue`：继续作为目标和习惯共用容器，负责日记加载、保存、草稿保护与关闭；布局改为右侧全高抽屉，桌面最大宽度 56rem，窄屏占满视口。
- `JournalEditor.vue`：保留现有 props/emits、Markdown、图片和错误状态，扩大输入与预览区域，打开时聚焦输入。
- `JournalTimeline.vue`：继续负责历史记录展示，通过原有 edit/delete/preview 事件与容器通信。

## 交互与验证

顶部和底部固定，中间区域独立滚动。保留原生 dialog 的模态焦点管理、Escape、遮罩关闭与草稿确认；新增右侧滑入动效，遵循减少动态效果的系统偏好，并留出手机安全区域。

验证前后端类型检查、生产构建与现有单元测试；浏览器检查桌面与手机、深浅主题、输入聚焦、预览、保存与重新编辑，以及关闭时保留或放弃草稿。

## 验证结果

- `pnpm test`：60 项测试全部通过。
- `pnpm build:cloudflare`：前后端类型检查与生产构建通过。
- 桌面 1280 × 720：右侧抽屉宽 896px、全高 720px，输入框自动聚焦；已有记录点击编辑后定位输入框并保留原文。
- 平板 768 × 1024、手机深色主题 390 × 844：抽屉铺满可用视口，内容无横向溢出，顶部与底部状态保持可见。
- Markdown 预览切换、输入后启用保存、遮罩与 Escape 关闭时的草稿确认、继续编辑与放弃草稿均验证通过；关闭后恢复入口焦点及背景滚动。
- 本次浏览器验证没有提交或修改已有账号记录，保存接口沿用原有实现；重建期间旧页面曾请求已更新的动态资源，刷新到最终构建后恢复，最终回归没有新增控制台错误。
