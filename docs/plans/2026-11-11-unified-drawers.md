# 应用浮层统一为抽屉

## 目标

所有应用弹出界面使用右侧全高抽屉，窄屏铺满屏幕，包括编辑、设置、详情、预览和二次确认。保留原有数据操作与草稿保护。

## 组件边界

- `style.css` 提供统一 `app-drawer` 几何、遮罩、动效、宽度、背景滚动锁定与安全区域样式，尊重减少动态效果设置。
- 编辑、设置、日程、日记、删除 / 放弃确认、大图和导出组件继续承载各自业务；使用原生 dialog 和现有 useNativeDialog 管理模态、Escape 与焦点。
- 目标、习惯、设置和待办固定头部与操作区，中间内容独立滚动。原来的自定义居中遮罩改成原生 dialog，可正确与其他抽屉叠放。
- `ConfirmDrawer.vue` 展示通用确认；`useConfirmDrawer` 提供按调用方隔离的异步确认请求；`confirmation-queue.ts` 处理排队、取消和调用方卸载，未确认的操作不会继续执行。
- 备份、GitHub 和账号操作共七处浏览器 confirm 改为 await 确认抽屉。

## 验证

- 新增三项队列单元测试，覆盖确认 / 取消、请求方卸载、排队和应用退出清理；全量 76 项测试通过。
- 桌面真实浏览器检查十二个入口：目标编辑、习惯编辑、待办、设置、日期详情、目标日记、习惯日记、大图、删除、放弃草稿、长图导出、通用确认，均为右侧全高。
- 390px 手机深色主题验证所有抽屉铺满宽度，600px 确认抽屉也铺满宽度，未出现横向溢出。
- 验证 Tab 焦点留在抽屉中、Escape 仅关闭最上层、关闭后返回触发按钮、页面背景滚动锁定、底部保存按钮可见。
- 目标 / 习惯编辑保存正常；日记草稿取消关闭后保留，取消删除不移除记录，长图导出仍只有一张 PNG。
- 本地完整备份和旧版备份恢复均进入确认抽屉；取消保留数据，确认载入示例及确认恢复完整备份真实执行成功。
- 浏览器没有运行错误、控制台警告或原生 confirm。
