# 记录筛选与完整长图导出实施计划

**目标：** 在记录页按类型、具体目标或习惯、日期范围筛选，并把全部匹配记录保存为 PNG。

**架构：** 服务端在分页前应用筛选，列表与导出共用查询构建逻辑。导出重新遍历全部匹配分页，在屏幕外渲染专用只读排版；等待图片和字体加载后生成一张完整图片。过长内容等比缩放，控制画布尺寸并保留全部内容。

**技术栈：** Vue 3、TypeScript、Tailwind CSS、Zod、按需加载 html-to-image。

## 组件边界

- `RecordsView.vue`：组织筛选、列表与来源标题，保留现有删除和大图行为。
- `records/RecordsFilters.vue`：接收筛选值和主体选项，通过 update 事件修改筛选。
- `records/RecordsImageExport.vue`：保存图片入口与生成状态、结果预览对话框。
- `records/RecordsExportSheet.vue`：接收记录、来源标题与筛选摘要，呈现完整正文和照片。
- `useRecordsImageExport.ts`：分页读取、取消、渲染、图片 URL 生命周期。
- `journal-feed.ts` / `record-image-export.ts`：共享筛选校验、分页遍历、单张长图尺寸计算。

1. 为共享筛选与完整分页读取补测试，覆盖日期边界、无效条件、重复页和失败。

4. 通过 pnpm Catalog 引入 html-to-image，仅生成时加载；全部筛选记录合并为一张 PNG，超长内容等比调整分辨率。
5. 更新 README 与 API 参数说明；运行单元测试、构建与本地 API 测试。
6. 浏览器验证桌面与手机深色主题、超过一页的完整导出、照片、错误、取消与重试。

## 验收

- 筛选发生在分页之前；日期边界包含当天，反向区间有明确提示。
- 导出包含尚未手动加载的匹配记录；不带按钮和应用导航。
- 正文、表格、代码及图片在输出宽度内展开，一张长图完整覆盖全部内容。
- 生成期间可取消，失败后可重试，关闭时释放图片 URL。

现有工作区包含用户尚未提交的修改，本次在当前代码上增量实现并保留这些修改。

## 快捷日期补充

- 记录筛选新增全部日期、今天、昨天、最近 7 天、最近 30 天、本周、本月。复用本地日期工具；最近 N 天包含今天，本周从周一、本月从 1 日算至今天。
- 快捷操作一次更新起止日期，保留类型和具体主体；手动输入范围后匹配对应选项，非预设范围标记为自定义。月初等范围重合时保留用户所选选项。
- 日期单元测试覆盖跨月、跨年、闰日、周一与周日；全量 67 项测试与生产构建通过。
- 真实浏览器验证所有预设范围与筛选条数、主体保持、手动输入、月初重合、长图导出与手机深色主题；390px 无横向溢出，浏览器无运行错误。
