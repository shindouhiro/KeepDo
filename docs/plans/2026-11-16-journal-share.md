# 记录链接分享实现方案

目标：从记录时间线分享单条完整图文、单条连续文字片段或某天全部记录，接收者无需登录。

架构：默认固定快照，独立保存文字、标题和图片，不随原记录变更。32 字节随机令牌作为访问凭据；所有者可撤销链接。前后端使用共享 Zod 模型，沿用 Vue Composition API、原生 dialog 抽屉和 Cloudflare D1。

## 组件与接口

- `JournalTimeline.vue`：通过 `shareable` 开启分享按钮，向父组件发送 `share(entry)` 和 `shareDay(date)`。
- `RecordsView.vue`：组合入口及抽屉，只持有当前分享目标。
- `JournalShareDrawer.vue`：接收单条、日期或管理模式；提供范围、预览、生成、复制和撤销，关闭时保护片段草稿。
- `useJournalSharing.ts`：封装请求、加载、错误、复制和撤销确认状态。
- `ShareContent.vue`：接收快照与 ID 前缀，复用 Markdown 和图片显示。
- `PublicShareView.vue`：公开阅读、加载与失效状态；独立启动，不初始化账号应用。
- `server/journal-share.ts`：归属检查、预览版本校验、原子快照和图片复制、公开读取、撤销。
- `0010_journal_shares.sql`：新增独立分享表与分享图片表，撤销与账号删除均级联清理图片。

## 交互与边界

整天分享直接查询数据库全部匹配记录，不使用前端分页或筛选结果。生成前预览完整内容；预览后内容变化返回 409，要求重新预览。每次生成最多 200 条、8 MB 附件图片，每账号最多 100 个链接、50 MB 分享图片。片段必须是原文中连续的非空文字，不含附件。外链 Markdown 图片仍由原外链提供，不在附件快照范围内。

公开接口只返回快照内容与分享时间，不返回用户名、用户 ID、主体 ID、原记录 ID 或版本。公开 HTML、JSON 和图片禁用缓存与搜索引擎收录，并设置 no-referrer。撤销不能收回已下载或截图的内容。

## 实现与验证步骤

1. 增加共享校验、D1 迁移和分享后端；验证权限、快照不变性、图片令牌隔离和撤销。
2. 接入时间线按钮、抽屉与独立公开页面，复用既有组件与平台请求通道。
3. 使用 `pnpm test` 验证单元测试，`pnpm build:cloudflare` 验证前后端类型和生产构建。
4. 应用本地数据库迁移，启动 Worker，用 `pnpm exec node --test tests/journal-share.integration.ts` 验证真实 API。
5. 浏览器实测完整分享、片段、整天预览、管理撤销、公开页面和窄屏布局。
6. 更新 README 和 AGENTS 接口说明；线上发布仍沿用 `pnpm run deploy`。

## 验证结果

- 单元测试 113 项通过，包含分享校验、中文正文 UTF-8 容量限制和图片级联清理。
- 独立本地 D1 的全部 API 集成测试 37 项通过；容量限制补充后，分享集成测试再次全部通过。
- 前后端类型检查、Cloudflare 生产构建和部署 dry-run 通过；未发布线上。
- 浏览器实测单条预览、连续片段、链接生成与复制、整天预览、管理撤销、失效页面、焦点返回及片段草稿关闭确认。
- 390px 窄屏下，公开页与抽屉无横向溢出；公开页验证系统深色主题。
- 分享正文与图片索引合计限制 1.5 MB，保留数据库单行容量余量。
