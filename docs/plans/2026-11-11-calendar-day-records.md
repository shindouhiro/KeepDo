# 日历记录限定所选日期

## 目标与方案

点击日历中的目标或习惯后，抽屉只显示和编辑所点日期的图文记录，新增记录也归属该日期。

- `JournalDialog` 负责当日编辑与展示，将所选日期传给 `useJournal`。
- `useJournal` 复用记录列表 API，以主体类型、主体 ID 和相同的开始、结束日期在服务端分页前筛选；刷新和加载更多沿用相同条件。
- 日期变化时取消旧请求并清空列表、游标和编辑状态；编辑与保存检查记录日期，保存成功后的异步回填也检查日期。
- 抽屉显示「当日记录」及具体日期，全部历史仍在主导航「记录」中回看。

## 验证结果

- `pnpm test`：73 项通过。
- `pnpm test:api`：16 项通过，包含同一主体和日期下超过一页记录的筛选、分页与账号隔离。
- `pnpm build:cloudflare`：前后端类型检查与生产构建通过。
- 浏览器使用本地测试账号验证 11 月 9 日、10 日的习惯记录互不混入，11 日无记录时为空；10 日新增、编辑和刷新均保持当天范围，记录页仍展示两个日期。
- 目标日记同样只展示所选日期；390px 手机视口页面宽度与滚动宽度一致，控制台无警告或错误。
