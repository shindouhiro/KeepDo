# 图文记录删除实现计划

目标：目标、习惯的图文记录支持删除，必须经过二次确认。

设计：时间线和编辑表单只发出删除请求；共用 `JournalDeleteDialog` 展示日期、内容摘要、不可恢复提示、取消与确认按钮，默认聚焦取消。`useJournalDeletion` 管理待删除记录、请求状态及错误；页面容器负责删除后的列表与编辑器状态。后端在同一条 SQL 中校验账号、主体与版本，删除记录后由外键级联删除图片。

1. 后端增加 DELETE 接口、版本参数校验和账号隔离；补真实 API 测试，覆盖图片清理、版本冲突、日期标记及同日多记录。
2. 增加共用确认弹窗与删除 composable，接入编辑器、主体时间线与总记录页；阻止重复提交，失败保留内容，成功后同步摘要并使旧列表请求失效。
3. 执行单元测试、真实本地 API 测试、类型检查和生产构建；浏览器验证取消、确认、错误反馈及删除后的界面状态。
4. 沿用现有 Cloudflare 发布流程，验证线上删除接口；不操作用户已有记录。
