# 日历计划展示优化实施计划

**目标：** 在日历日期内直接看见每一个目标、习惯和待办，改善日期导航、状态层级和窄屏阅读。

**架构：** 保留现有 Pinia 数据与日期详情弹窗。`CalendarPlanner.vue` 负责周/月切换、日期导航和布局，接收日期、目标、习惯及待办，发出日期选择和查看详情事件；`CalendarPlanItem.vue` 仅展示单条计划并发出查看事件。共享纯函数负责日期范围、计划映射及状态计算。

**技术栈：** Vue 3、TypeScript、现有 Tailwind CSS 与 Lucide，无新增依赖。

## 实施步骤

1. 在 `shared/calendar.ts` 增加周/月日期范围与逐日计划映射；为跨年周、闰年月份、完整计划列表、历史过滤和完成状态补充 `tests/calendar.test.ts`。
2. 创建日历面板和计划卡片，所有计划完整展开，标题换行，不通过数量或省略项替代内容。周视图窄屏采用卡片网格，月视图保留可横向滚动的七列。
3. 在 `TodayView.vue` 替换原数量式周历，保留下方行动管理和现有详情、编辑能力。
4. 运行 `pnpm test` 和 `pnpm build`，使用本地浏览器验证周/月导航、计划完整性、详情、深色与移动布局。

## 视觉与交互

沿用靛蓝主色，以细分隔线、轻量底色与明确排版建立日历秩序。目标用靛蓝、习惯用琥珀、待办用蓝灰；同时提供图标及文字，截止和逾期带明确标签。选中日以浅底色和边缘强调，今天单独标识。日期、计划卡片和新增按钮均可键盘操作，并有唯一描述性 ID。

## 验证结果

- `pnpm test`：17 项测试通过；`pnpm build`：Vue、Worker 类型检查与 Vite 构建通过。
- 使用临时独立样例验证 TodayView，未写入用户账号数据；当天 9 项计划与全周 36 张卡片均完整展示，无重复 ID。
- 日期卡片可打开详情，添加计划正确带入当前日期；月视图 35 天完整展示，月份导航正常。
- 1280px 桌面、390px 手机、浅色及深色显示正常，无页面横向溢出；手机月历在自身容器内横向滚动。
- 浏览器控制台无警告或错误，临时样例文件已清理。
