# 日记图片粘贴

## 目标与边界

目标和习惯日记均支持在编辑器内使用 `⌘ / Ctrl + V` 粘贴截图或图片。图片作为附件进入现有预览、压缩、移除和保存流程，保留每条记录最多六张、JPG / PNG / WebP、原图大小与分辨率限制。

## 实现

- `src/lib/journal-clipboard.ts` 提取剪贴板图片，优先读取 items，必要时使用 files，避免同一张图片被两个列表重复添加；纯文字和普通文件不触发图片处理。
- `JournalEditor.vue` 在表单范围内监听 paste，文件选择和粘贴统一调用 addImages。处理和保存期间不接收新图片。
- 普通文字维持浏览器原生粘贴；混合图片与文字在处理图片前将文字插入当前选择位置，并遵循 5,000 字上限。图片处理结束后恢复原输入焦点，用户已移至其他控件时不抢回焦点。
- 不引入剪贴板读取授权或全局事件监听；关闭编辑器沿用现有临时图片 URL 清理与草稿保护。

## 验证

- 新增四项剪贴板提取单元测试，覆盖多图、去重、空输入、文字、其他文件、files 回退与不支持图片格式。
- 隔离 Chrome 中通过真实剪贴板和 `⌘ + V` 验证截图、普通文字、图片与文字混合粘贴；草稿和焦点保留。
- 验证超出六张拒绝、GIF 格式提示、移除后补充、保存六张习惯图片后刷新重新编辑，以及已保存图片参与数量限制。
- 验证目标日记选区替换、5,000 字限制、纯图片记录保存和 390px 手机布局；无横向溢出、运行错误或控制台警告。
- `pnpm test` 与 `pnpm build:cloudflare` 用于最终回归。
