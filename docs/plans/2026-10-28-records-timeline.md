# 记录总时间线实现计划

**目标：** 主导航新增「记录」，按日期倒序查看当前账号所有目标与习惯的图文记录。

**实现：** 新增账号级分页接口 `/api/journal`，支持全部、目标、习惯筛选。复用现有时间线和图片预览组件；总览只读取记录，在卡片中标明目标或习惯名称，已删除主体保留历史记录并显示提示。

1. `server/journal.ts`：提取现有分页逻辑，增加账号级分页查询，校验筛选与游标；沿用账号和图片权限隔离。
2. `src/composables/useJournalFeed.ts`：负责筛选变化、取消旧请求、刷新和分页，防止过期响应覆盖当前筛选。
3. `src/components/journal/JournalTimeline.vue`：通过插槽展示来源信息，允许关闭编辑入口；现有弹窗行为保持兼容。
4. `src/components/RecordsView.vue`：承载筛选、时间线、加载、空状态、失败重试、加载更多与图片预览。
5. `Navbar.vue`、`KeepDoWorkspace.vue` 与 `stores/keepdo.ts`：加入记录页面入口，兼顾手机导航宽度。
6. 新增接口测试，检查跨主体排序、筛选、分页、游标校验和账号隔离；执行构建、测试及桌面/手机浏览器验证。
