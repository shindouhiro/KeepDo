# Issue #1：行动工作台体验改进

目标：降低日历纵向占用，让每日完成度更直观，并提供跨页面快捷收集、桌面分栏和轻量达成反馈。

架构：沿用 Vue 3、Pinia 与 Tailwind，复用现有待办编辑器和同步流程；徽章直接由原始行动记录派生，不增加数据库字段或独立积分账本。

## 方案与边界

- 采用有限预览与显式展开：相比无限滚动，保留周/月定位和键盘操作；相比仅缩小字体，能控制任务密集日期的高度。
- 快捷收集先采用应用内全局入口与 ⌘/Ctrl + K；浏览器插件、系统热键需要独立发布与权限设计，留待后续。
- 激励采用每日完成反馈与近七天的 1 / 3 / 7 天徽章；抽奖、皮肤、语音仪式留待明确产品规则后实现。

## 组件与数据流

- `CalendarPlanner`：紧凑周/月布局、收起、有限预览、日期详情入口；继续通过既有事件向父组件传递操作。
- `DailyProgress`：接收每日统计与紧凑模式，显示文字、进度环和完整达成状态。
- `DailyMomentum`：接收习惯、待办、日期与今天，派生选中日进度及近七天徽章。
- `KeepDoWorkspace` + `useQuickAdd`：管理全局添加状态及键盘事件，弹窗内编辑时不抢占快捷键。
- `TodoModal`：复用日期、优先级、目标关联和失败重试；保存成功发出事件，入口显示成功反馈。
- `TodayView`：组合日历、成长反馈及目标/习惯/待办分栏；手机保持单栏。

## 验证结果

- `pnpm test`：42 项通过，覆盖近七天跨月跨年、空计划、未来记录排除、徽章撤销和快捷键判定。
- `pnpm build`：Vue 与 Worker 类型检查、生产构建通过；`git diff --check` 通过。
- 浏览器验证：独立本地测试账号，单日 14 项计划完整展开；精简预览、日期详情、长标题、周/月切换、收起/展开和移动端选中日期自动定位均通过。
- 全局入口：今日、目标、记录、统计四页可添加；输入框、原生弹窗、设置弹窗中不抢占快捷键，关闭后恢复焦点。
- 持久化：快捷创建保留优先级与目标关联；本地代理注入 503 后草稿保留，重试后 API 中只有一条记录，安排日期与目标关联正确。
- 响应式：390px 手机、768px 平板与桌面验证通过，无页面横向溢出；新增交互元素均有描述性 ID，页面未出现重复 ID。
- 桌面控制台无 warning/error；模拟故障产生的 503 仅存在于临时测试代理。
