# 高清长图与剪贴板复制

## 目标

记录导出保持单张完整长图，增加适合放大的 SVG 格式和快速复制到剪贴板；保留 PNG 下载。

## 实现

- 一次克隆导出排版并内嵌字体、照片，生成保留完整文本与布局的 SVG；使用同一份 SVG 渲染 PNG，避免重复抓取和前后内容不一致。
- 普通 PNG 默认三倍分辨率，超长 PNG 仍受画布边长与像素预算约束；SVG 保留原始完整高度，文字和线条按矢量缩放。照片受原始图片分辨率限制。
- 导出抽屉默认选择 SVG，可切换 PNG；始终只有一个下载入口，点击一次只下载一张选定格式的图片。
- 复制按钮直接写入已生成的 PNG Blob，无需重新生成或异步下载；写入由用户点击触发，支持成功、处理中、不支持和权限拒绝提示。
- 关闭与重试均释放 PNG / SVG 对象 URL。旧复制请求完成后不更新已经关闭或重新生成的界面。

## 验证

- 78 项单元测试与生产构建通过，覆盖三倍尺寸、超长像素限制与保留 SVG 中文 / 原始高度。
- 真实 Chrome 下载 SVG 和 2280 × 5601 PNG，原生剪贴板复制后读回相同尺寸的 image/png。
- SVG 文件独立打开正常，文字区域按两倍比例放大，照片已内嵌并正常显示。
- 43 条跨分页记录生成一张 760 × 18227 的 SVG，首条、最后一条、页脚均完整保留；PNG 仍为单张，复制成功。
- 模拟权限拒绝和浏览器不支持，均有明确提示且保留下载；恢复接口后重试复制成功。
- 390px 手机深色主题无横向溢出，复制和格式选项可见；正常流程无浏览器错误或警告。
