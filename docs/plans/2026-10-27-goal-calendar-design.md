# 长期目标接入日历

**目标：** 用户选择每天展示进行中的长期目标，并在截止日标记提醒；空行动不能再显示完成 100%。

**架构：** 前端从当前账号已有目标派生日历展示，不修改数据库结构，不自动创建习惯或待办。共享纯函数统一目标完成判断、日期关联及每日行动统计。

**技术栈：** Vue 3、Pinia、TypeScript、Tailwind CSS、Node 测试、Cloudflare Workers。

## 约定

- 进行中目标从创建日开始每天展示；无截止日也展示。
- 截止日增加明确文字标记，并可查看该日目标。已达成目标不继续占据每日进行中列表，但保留截止日的关联展示。
- 逾期未达成的目标继续展示并标记逾期。
- 选中日期的目标卡显示当前累计进度，不伪造历史进度快照。
- 当日行动完成率只统计习惯和该日待办。零行动显示未安排；所有实际行动达成后才显示 100%。

## 实施

1. `shared/calendar.ts`：统一行动统计，新增目标进度、完成与日期筛选逻辑。
2. `tests/calendar.test.ts`：验证无截止目标、日期边界、已完成与逾期目标、里程碑和空行动。
3. `src/components/CalendarGoals.vue`：展示当日关注目标、当前进度及截止状态，发出编辑事件。
4. `src/components/TodayView.vue`：为周历补目标数量及截止标记，接入目标区，纠正进度文案。
5. `src/stores/keepdo.ts`、`Navbar.vue`：统一行动统计，空行动不显示完成；复用已有目标弹窗。
6. 运行测试、类型检查和构建；本地浏览器检查新建目标后回到日历、切换日期、深浅主题与窄屏；部署原有 Worker 并核对线上资源。

## 验证结果

- 12 项自动化检查通过，包括创建日期边界、无截止日、截止和逾期、已完成目标、里程碑及零行动。
- 本地浏览器已验证新建目标后立即出现在周历、编辑截止日后提醒更新、切换日期显示逾期、刷新后保留。
- 深色窄屏和浅色桌面均检查；窄屏没有横向溢出。
- 类型检查、生产构建通过，已发布到原有 Cloudflare Worker；线上入口及脚本、样式与本次构建产物匹配。
- 本次只增加前端派生展示，未迁移或重写用户业务数据；专用本地测试账号已清理。
